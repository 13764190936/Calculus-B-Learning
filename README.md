# Calculus-B-Learning

A public archive for Calculus B learning progress, lesson notes, concepts, methods, practice, and review.

## Teaching principles
- Follow the teacher's original Notion notes, recordings, slides, and lecture order.
- Teach one small concept at a time.
- Explain the teacher's theory accurately, then simplify it with plain-language explanations and occasional analogies.
- Include short interactive questions and wait for the learner to confirm understanding before moving on.
- Distinguish teacher material from supplementary explanations.
- At the end of each study session, update progress and add a concise lesson log.

## Repository structure
- `PROGRESS.md` — current position and next step.
- `SYLLABUS.md` — course map and source policy.
- `lessons/` — session logs.
- `knowledge-base/` — concepts, formulas, and problem-solving methods.
- `mistakes/` — errors and corrections.
- `TUTOR_GUIDE.md` — persistent teaching preferences.
